## 跨仓晋升放行（已落地）

血缘包从源仓晋升到目标仓，两条接收方式二选一、不可同时打开（台参数 `promo_receive_mode`）：

- **快照表**：`promo_snapshot_edges` 封存整包每条边指纹与条数，再整包写入目标仓边表；半包（条数/指纹对不上）直接拒写，边表不留残缺边。
- **文件凭证**：整包物化成 `instance/promo_payloads/<凭证号>.json`，仅在旁路凭证 `promo_receipts` 记一行，不写快照表。

工程落点：

- 放行经 `BEGIN IMMEDIATE` 排他写锁 + `promo_release_locks` 单行锁，两侧值班抢点只有一个能进入；凭证表 `package_id UNIQUE` 保证单次写入，失败统一中文报错并整体回滚。
- 全量抓取入库（`/api/promo/ingest`）先按凭证整包指纹与条数核对目标仓边表，对不上记一条“已拦”并拒绝入库。
- 覆盖对账页显示晋升来源与覆盖进度；边关系页显示同源条数；晋升放行页对照节点目录、边表、影响卡片与各表凭证。
